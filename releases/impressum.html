How it was made

These pages, and parts of the renderer behind them, were written with the help of Claude. The site exists to show the work and to be useful to anyone drawing Vega charts: what the renderer does, what it does not do yet, and a place to try it rather than take a table's word for it.

Data

The pages are static files served by GitHub Pages, which is operated by GitHub, Inc. GitHub records request data such as IP addresses in its own server logs, described in the GitHub Privacy Statement. This site sets no cookies, runs no analytics, and stores nothing about you.

Pages here load Vega from the jsDelivr CDN, and the demo fetches example datasets from vega.github.io, so those hosts see a request from your browser when you open a page. The mark playground also loads two example images from vega.github.io.
